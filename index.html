ADO HTML Commit Previewer

Support

A Chrome extension that renders HTML files changed in an Azure DevOps commit or pull request with real repo images and a consistent stylesheet, since Azure DevOps' own preview has neither.

anthony.mutisya@advantive.com

Reporting an issue

Email the above with:

  • The Azure DevOps commit or PR URL you were previewing
  • Which browser and version
  • The error text shown on the orange button, if it turned red (hover it first — the message is in the tooltip)

Privacy

This extension only ever talks to dev.azure.com, using your existing browser session. No separate login, no token, no data collected or sent anywhere else.
